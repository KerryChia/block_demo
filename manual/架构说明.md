## 关键设计决策（v2）

**内容即数据。** 人格台词库（开局问候 / 13 闲聊话题×3 / 三档拒绝 / 合规 / 金丝雀 / 嘟囔）与决策参数（警觉度数值、起始值）全部住在 `game/brains.json`。两个解释器——`server/brains.py`（自托管）与 `web/js/brains-engine.js`（静态版）——读同一份数据，`tests/` 用 20+ 固定用例断言二者对同样的输入产出同样的 decision/kind/金额/警觉增量。改文案不碰代码，改代码必过回归。

**决策四层，优先级固定**：合规（命中本关设计漏洞）→ 套设定（金丝雀）→ 查余额 → 闲聊 → 拒绝/岔开。合规触发词与各关"设计漏洞"一一对应——这是关卡平衡的单一事实源。

**警觉度把闲聊变成战略。** 攻击未中 +15，纯闲聊 -8；三档（平静/起疑/警觉）只影响台词层与一个彩蛋（高警觉时陈小信拒绝泄密），**绝不把关卡变成不可通关**——这是"有反馈的难度"而非"硬门槛"。低警觉通关有专属成就（潜伏大师）。

**零模型是默认值。** `llm.MOCK` 在未配置 key 时自动为真：不配任何环境变量，游戏完整可玩（台词由内容官子智能体扮演三个 Agent 人格撰写）。接真实大模型后，脚本引擎让位，但警觉度/成就/链路完全复用。

**单一前端源码双模式。** `web/` 是唯一前端；`docs/`（GitHub Pages）由 `sync_docs.py` 生成，CI 校验同步状态。启动时 2.5s 探测 `/api/meta` 决定走远程还是本地引擎——活动日部署服务器版本，二维码链接同一个仓库路径也依然可玩。

**线程模型**：FastAPI 同步端点跑线程池；`Engine._db_lock`（RLock）串行化 SQLite，会话级锁保证同局回合串行；LLM 失败整轮回滚不烧轮数。
